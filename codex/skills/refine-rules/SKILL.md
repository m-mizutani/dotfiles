# AGENTS.md の整備

言語、依存関係、ビルド・テスト・lint のコマンド、CI、フォーマッター、既存の `AGENTS.md`、テストの書き方を確認する。コードを読めば分かるディレクトリや識別子の一覧は、指示文に書かない。

ビルドの失敗、CI に必要な検証の不足、秘密情報を含むファイルが `.gitignore` の対象になっていないこと、既存の指示と実装の不一致を見つけた場合は、ルールを書く前に根拠を示す。修正が必要な場合はユーザーの承認を得る。

リポジトリのルートには全体に適用する `AGENTS.md` を配置する。特定のディレクトリだけに適用する規約がある場合は、そのディレクトリにも `AGENTS.md` を配置する。実行できる検証コマンド、コードからは分からない制約、設計上の重要な判断、変更時に更新が必要なドキュメントを、英語で簡潔に記録する。

既存のファイルを更新する場合は、変更内容を示す。今回の依頼で更新がすでに許可されていれば、同じ承認を求めず作業する。新たな判断が必要な場合だけ、`AGENTS.md` の User Decisions に従う。全プロジェクトに適用する `~/.codex/AGENTS.md` は、利用者が明示的に求めない限り変更しない。

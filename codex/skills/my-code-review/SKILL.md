# コードレビュー

## 利用者向け文章・i18n の品質（必須）

`AGENTS.md` の User-Facing Text を適用する。文章が対象に含まれる場合は、共通の基準で確認する。出力を絞り込む際も、文章の修正必須の指摘を省略しない。

レビュー対象を明示されていなければ、作業ブランチではデフォルトブランチとの merge-base からの差分と未コミット変更、デフォルトブランチでは未コミット変更とする。差分だけで判断せず、変更ファイル全体、呼び出し元・先、同種の既存実装、テスト、`AGENTS.md`、関連 spec を読む。

正確性、テストで検証する範囲、spec との一致、保守性、公開インターフェース、エラー処理、セキュリティ、ドキュメントのうち変更に関係する観点を確認する。見つけた候補は、出力前に実コードとプロジェクトの指示で裏付ける。

結果は対象を1行で示した後、`Must-fix`、`Should-fix`、`Consider` の順に整理する。各指摘には `file:line`、問題、発生する結果、具体的な提案、確信度を含める。重大な指摘がなければ、その旨だけを報告する。このスキルはコードを変更しない。

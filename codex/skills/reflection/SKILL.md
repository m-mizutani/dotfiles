# 振り返り

対象が指定されなければ、現在の会話を対象にする。過去のセッションを読む必要がある場合は、Codex が保存するセッションデータの場所とアクセスできるかを確認し、読む範囲を限定する。ユーザーの発言だけで結論を出さず、直前のアシスタントの提案や操作と合わせて確認する。

各項目について、何をしたか、なぜ問題だったか、別のリポジトリにも適用できるかを判断する。既存の指示で防げる問題なら、指示を追加しない。一般的な原則は、全プロジェクトに適用する指示の候補として提示する。ただし、利用者の明示的な依頼なしに全プロジェクト用のファイルを変更しない。プロジェクト固有の事実は、対象リポジトリの `AGENTS.md` に記載する候補とする。

更新前に、指示の追加、既存の記述への補足、記述の統合、追加不要のいずれにするかと、その理由を示す。今回の依頼で対象と更新内容がすでに許可されていれば、同じ承認を求めず作業する。新たに承認が必要な変更だけ、`AGENTS.md` の User Decisions に従って確認する。指示は英語で書き、具体的なファイル、コマンド、制約を記録する。

# herdr-tab-name

herdr のタブ一覧から、各タブの作業内容と段階を確認できる状態を保つ。

## ラベル

`[<段階タグ>] <作業内容>` の形式にする。作業内容は日本語 8〜15 文字の体言止めとし、
ファイル名、リポジトリ名、引用符、絵文字、句読点を含めない。

主な段階タグは次のとおり。

| タグ | 状態 |
| --- | --- |
| `plan` | 設計・仕様検討 |
| `impl` | 実装 |
| `refine` | 実装後のレビュー指摘対応 |
| `research` | 調査 |
| `review` | レビュー |
| `ops` | 運用 |
| `release` | リリース |

該当するタグがなく段階を判断できない場合は、作業内容だけを使用する。

## 実行

`exec_command` で次の1コマンドだけを実行する。

```text
herdr-label "<ラベル>"
```

Herdr のソケットは Workspace sandbox から接続できないため、`exec_command` には次を指定する。

- `sandbox_permissions`: `require_escalated`
- `justification`: `Herdr のタブ名と pane 名を更新してよいですか？`
- `prefix_rule`: `["herdr-label"]`

環境変数の確認、条件分岐、コマンド連結は行わない。`herdr-label` は herdr の外、応答しない
ソケット、古い ID を処理して常に終了コード 0 を返すため、出力がなくても再実行しない。

## 実行する時点

- セッションで最初の作業指示を受けた直後
- 作業内容が変わったとき
- 作業段階のタグが変わったとき

同じ作業を同じ段階で継続している間、挨拶や雑談だけのとき、単発の質問に答えるだけの
ときは実行しない。ただし、セッションで一度も実行していない場合は最初の作業指示で必ず
実行する。

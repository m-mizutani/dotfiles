# 別プロセスによる Codex レビュー

## 利用者向け文章・i18n の品質（必須）

`AGENTS.md` の User-Facing Text を適用する。レビュー依頼文に共通の基準を含める。文章が対象に含まれる場合は独立した確認項目とし、結果の採否にも同じ基準を使う。

対象が指定されなければ、作業ブランチではデフォルトブランチとの差分と未コミット変更、デフォルトブランチでは未コミット変更を対象にする。対象とプロジェクトの `AGENTS.md` を確認してから、独立したレビュー を依頼する。

- 未コミット変更: `codex review --uncommitted <review instructions>`
- ブランチの差分: `codex review --base <default-branch> <review instructions>`
- 指定したコミット: `codex review --commit <sha> <review instructions>`

レビュー依頼文には、対象、確認する観点、プロジェクトの指示を優先すること、指摘に `file:line` と根拠を付けることを書く。`codex review` が利用できない、または実行のための承認が得られない場合は、自己レビューへ黙って切り替えず、その状態を報告する。

結果をそのまま採用しない。各指摘について実装・spec・プロジェクトの指示を確認し、修正、却下、ユーザー判断待ちのいずれかを理由とともに整理する。修正はユーザーが求めた場合だけ行う。

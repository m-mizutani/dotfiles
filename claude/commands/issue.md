このコマンドへの指示やこれまでの議論に基づき、解決すべき課題を Issue にまとめる。英単語3〜4語程度の slug を付け、`.cckiro/issues/` 以下に Markdown ファイルを作成する。

例:
slug: enhance-error-handling
path: .cckiro/issues/enhance-error-handling.md

Issue には、次の概要だけを書く。

- as-is: 現状がどうなっているか
- to-be: どのような機能が必要か



- 実装の詳細は書かない
- この Issue をもとに別途要件定義や設計を行うため、課題だけをまとめる
  - 会話や指示から分からない内容を、推測で補ってはならない
- 本文は日本語で書く
